# Connector Admin - Agent Instructions

Use `.github/copilot-instructions.md` as the canonical, always-on project guidance for coding assistants.

Key operating rules:

- Use Admin Controls first, then Fluent UI.
- Prefer MDL2 icons (`@fluentui/react-icons-mdl2`).
- Never work directly on `main`; use feature branches.
- Promote only approved files to `main`.
- For connector updates: saving details is not enough; changes reflect in Copilot only after connector sync.
