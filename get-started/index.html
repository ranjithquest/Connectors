Set up the boilerplate

Choose your setup method below. Each path gets you running locally with the repo cloned, dependencies installed, and push access configured.

Install VS Code and the GitHub Copilot extension. Clone the repo using the URL above, open the folder in VS Code, then run setup.sh to install dependencies and configure push access.

1Install the GitHub Copilot extension from the VS Code marketplace.
2Create a folder with a feature name on your system and open it in VS Code.
3Clone the repo — VS Code will prompt you to sign in with GitHub to access this private repo.
git clone https://github.com/gim-home/Connectors.git
4Open a terminal and run setup.sh to install dependencies and configure push access.
./setup.sh

Design & share

Share a product spec, user story, or Figma URL with Copilot. It builds the concept directly in the app using Fluent UI components. Iterate freely.

Most Admin Center experiences use Fluent V8, with some areas migrating to V9. If Copilot picks the wrong component, find the right one in the resources and paste its link into chat — or just tell Copilot explicitly, e.g. "Use MessageBar from Fluent V8".

Each feature lives on its own git branch off main, so you can work on multiple in parallel without them stepping on each other. For each new feature:

1Create a new feature — either ask Copilot in chat ("create a new feature called dark mode toggle"), or click "New feature" on the about page. Both branch off main and switch you to the new branch automatically; just make sure you commit or stash any in-progress work first.
2Work on the feature with Copilot — iterate freely. Your changes stay isolated to this branch.
3When ready to share, run ./publish.sh — it commits your changes, pushes the branch, and gives you a shareable preview URL.
./publish.sh
4To switch between features locally, check out the branch in your terminal — Copilot will pick up where you left off on that branch.
git checkout owner/feature-name
5The about page lists every feature you have locally under "Features on your local" and flags any with unpublished changes.
